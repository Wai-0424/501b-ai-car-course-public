# 車一控制台（2026-10-13）

本機原始碼：`firmware/car1/orin_tools/`。Orin 部署位置：
`~/car1_ws/src/car1_bringup/tools/manual_console/`。
工具直接沿用車一的 `UartBridgeNode`、`BridgeCore`、`uart_protocol` 與 `steering_law`；沒有修改 BM 韌體或原有 ROS 節點。

## 啟動

先啟動相機與感知常駐層，停止所有會佔用 `/dev/ttyTHS1` 的其他行駛程式。

```bash
source /opt/ros/jazzy/setup.bash
source ~/car1_ws/install/setup.bash
cd ~/car1_ws/src/car1_bringup/tools/manual_console
timeout --foreground -s INT -k 10 7200 python3 -u manual_console.py
```

本次連結由程式產生，讀 `/tmp/car1_manual_console_link.txt`。
預設只在 `127.0.0.1:8092` 監聽。要從其他電腦連線，可用 `--host` 或 `CAR1_CONSOLE_HOST` 指定車一的 Tailscale 位址。每次服務啟動都會產生新的控制 token。
請使用完整連結。頁面將疊圖與鳥瞰代理到同一埠，供內嵌瀏覽器顯示。

## 操作

- 選擇自動循線或手動控制，再確認現場。預設未允許輪子前進，開始後只轉向。
- 要前進須勾選允許輪子前進。自動模式按開始即循線；手動模式按住前進按鈕或空白鍵才走。
- 目標輪速由頁面選擇，可在 0–45% 間調整；舵機命令上限 ±20°。每次開始前可選前進累計上限 5–120 秒。
- 自動模式沿用近點 P 控制與航向修正：近點 0.61 m、遠點 1.10 m，預設增益 150 °/m、20 °/rad，轉向濾波時間常數 0.08 s。
- 自動模式必須有新鮮且有效的近點（0.3 s 內）。沒有有效航向時只使用近點；沒有近點就終止工作階段。
- 頁面指令超过 0.35 s 未更新、BM 雙向通訊中斷、故障或操作員停止會停止，需重新開始。
- 速度最多每秒上升 8%；放開、停止與故障歸零不經上升限制。
- 切換分頁或視窗失焦會終止工作階段。先停止再切換模式。
- 再次開始前，需要新鮮的帶方向輪速 `vL/vR` 確認两輪低於 3 RPM 持續 0.3 s，且故障停車閘門放行。
- 頁面顯示的是實際寫出的受限輪速命令與 `vL/vR` 回授。舵機角度是命令，沒有實測角度回授。
- UART 使用私有命令訂閱，另以 `/cmd_vel` 將實際受限命令提供監看頁。不要同時啟動其他行駛層；控制台會拒絕與其他 `/cmd_vel` 發布者同時啟用。

記錄：`~/car1_ws/run/manual_console_<時間>/commands_feedback.csv`，20 Hz，含要求、實際指令、RPM、位置 tick、duty、故障、ack 與停止原因。
此工具不另外保存原始相機影像。
