# 車2 編碼器 A/B 相接線測試（2026-10-12）

車子拆掉重組後，確認四條編碼器線是否接對。**這份韌體不輸出 PWM、不碰 PCA9685，用手轉輪子**；D2/D3/D8/D9 被設成輸出低電位，避免驅動板輸入腳浮接。

| 馬達 | A 相 | B 相 | 前進方向的計數慣例（沿用 `car2_car_control`） |
|---|---|---|---|
| M1 左輪 | D4 | D5 | **正** |
| M2 右輪 | D10 | D11 | **負** |

## 刷寫與讀取

```bash
arduino-cli compile --fqbn HT32:HT32:BM53A367A --build-path build/car2_encoder_phase_test firmware/car2/investigations/2026-10-encoder-phase-test/car2_encoder_phase_test
arduino-cli upload  --fqbn HT32:HT32:BM53A367A --input-dir build/car2_encoder_phase_test
```

刷寫用 e-Link32 Pro。序列埠 115200，用任何終端機開 BMduino 的 USB COM 埠（連續讀取：`arduino-cli monitor -p COMx -c baudrate=115200`）。

## 測法

1. 驅動板電源關掉（這份韌體不會轉馬達，但手轉時避免反電動勢進驅動板）。
2. 只轉**左輪**往車子**前進**方向約 1 圈，停 1.5 秒，看報告。
3. 只轉**右輪**往車子**前進**方向約 1 圈，停 1.5 秒，看報告。
4. 指令：`z` 歸零、`s` 印四條腳目前電位、`r` 重印說明。

## 報告怎麼看

| 報告內容 | 意思 | 處理 |
|---|---|---|
| 方向 OK | 往前轉的正負號符合慣例 | 不用動 |
| 方向相反 | A、B 兩線接反（或該輪編碼器裝的方向和以前不同） | 對調該顆編碼器的 A、B 線；或把 `car2_bts7960_basic.ino` 的 `ENC_SIGN_M1/M2` 乘 -1 |
| 有一相完全沒有邊緣 | 那條線斷線或接錯腳 | 檢查該條 A 或 B 線 |
| A、B 邊緣數差很多 | 一相接觸不良 | 重插端子 |
| 非法跳變 > 2% | 訊號雜訊或接觸不良（轉太快也會） | 慢一點轉再測；仍多就檢查接地與屏蔽 |
| 另一輪也有明顯計數 | 左右編碼器接反（M1/M2 對調）或兩輪機械連動 | 對調兩顆編碼器的接頭 |
| 圈數 | 轉 1 圈約 1289 計數；明顯不同代表編碼器線數、減速比或沒轉滿 | 比對轉的圈數 |
