# 車2 煞車版 UART 規格（car2_bts7960_brake，2026-11-17）

Serial3（BMduino ↔ Orin），460800 baud，8N1，每包一行，結尾 `\n`。與舊版相容：舊 Orin 不送 `brk`、不認 `led 4/5` 不受影響。

## Orin → BMduino：CMD

```
<CMD,seq N,fwa F,bwl L,bwr R,led X,brk B,cs HH>\n
```

| 欄位 | 範圍 | 缺少欄位時 | 說明 |
|---|---|---|---|
| seq | 整數 | 保持 | STA 的 ackseq 回傳 |
| fwa | -60~60 | 保持 | 前輪角度（煞車中照常跟隨） |
| bwl / bwr | -100~100 | 保持 | 左/右輪目標速度 %；煞車中被忽略；=0 只是放開滑行，不煞車 |
| led | 0~5 | 保持上一個 | 0~5 以外的值整個忽略 |
| brk | 0 / 1 | **視為 0（每包重設，不沿用）** | 1 = 緊急煞車；0 或 1 以外的值都當 0 |
| cs | 2 位十六進位 | — | `<`與`>`之間、cs 欄位以外全部 byte 的 XOR；錯誤整包丟棄 |

- 頻率 30~60 Hz，整包單一 write。
- 500 ms 沒有合法 CMD：bwl/bwr 歸 0（滑行）、brk 視為 0、led 強制 3。
- 觸發期間每個 CMD 都送 `brk 1`；解除送 `brk 0` 或省略欄位。

### led 模式

| 值 | 模式 |
|---|---|
| 0 | 熄滅 |
| 1 | 白色常亮 |
| 2 | 橘色爆閃 2 Hz |
| 3 | 紅色呼吸（失聯時韌體自己切） |
| 4 | 白燈 1 Hz 閃爍（亮 0.5 s／滅 0.5 s）。相位從 led 由別的值切到 4 的那一刻起算；連續收到 4 不重置 |
| 5 | 煞車燈，紅色恆亮（brk 作用中韌體自己切；Orin 也可直接送） |

優先序：3（失聯）> 5（brk 作用中）> Orin 送的模式。STA 的 led 回報實際生效的模式。

## BMduino → Orin：STA（20 Hz）

```
<STA,ackseq N,S1 -1,rpmL ..,rpmR ..,vL ..,vR ..,f ..,led X,brk B,bkc N,cs HH>\n
```

| 欄位 | 說明 |
|---|---|
| f | bit0=M1 堵轉、bit1=M2 堵轉、bit2=PCA9685 故障、**bit3(=8)=上次煞車因滑移被放開**（下次煞車開始時清除） |
| led | 實際生效的模式（含韌體自己切的 3、5） |
| brk | **新增**。目前是否正在煞車 0/1（車1 的 brk 是位元欄，意義不同，Orin 要依車解析） |
| bkc | **新增**。自開機起的煞車次數，uint8，255 後回 0 |

## brk = 1 的行為

- 動作：兩輪致能保持開、RPWM/LPWM 同時拉低 = BTS7960 低側導通的短路煞車（不是反轉電流煞車）。
- 啟動時機：下一圈 loop（不等 60 Hz PID 週期），遠小於 20 ms。
- 不啟動條件：f 的 bit0/bit1（堵轉）、bit2（PCA 故障）有值；放開後 500 ms 冷卻內。
- 時間：最短 300 ms（BRK_MIN_MS）、最長 1000 ms（BRK_MAX_MS）、放開後冷卻 500 ms（BRK_COOL_MS）。
- 提早放開：兩輪轉速差相對起煞時偏離超過 max(25 rpm, 起煞轉速 15%)（暫定值，起煞後 60 ms 才判）；致能寫入失敗。
- 放開後：回到一般零速保持（滑行）。冷卻結束時若 brk 仍是 1 會再煞一次。
- 失聯：不做失聯煞車，維持滑行 + led 3。
- 煞車中 `bwl/bwr` 被忽略；放開後若 bwl/bwr 仍非 0 會以起步脈衝重新驅動。

## 台上測試（USB，不屬於 UART 協議）

`b MS`：不用 Orin 觸發煞車 MS 毫秒（最多 1000）；`b 0` 取消。
