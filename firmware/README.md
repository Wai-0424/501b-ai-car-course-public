# 韌體區導覽

firmware 以實體車輛為優先邊界；同一顆板子或同一種馬達不代表程式可直接跨車使用。

- [car1/](car1/)：車1專用程式、已使用的整合韌體、備用版與測試記錄。
- [car2/](car2/)：車2專用程式，含現行車用韌體（L298N 驅動板）、舊驅動板版、校正實驗與故障排查記錄。
- [common_tools/](common_tools/)：通訊、編碼器與測試台工具。名稱不代表所有內容都不帶硬體前提，使用前須讀個別註解。
- [investigations/](investigations/)：跨車或問題導向的一次性診斷，按日期保存。

## 放置規則

含特定車輛接線、校正常數、協定版本或安全限制的檔案放入 car1 或 car2。能跨車使用但帶有測試馬達前提的檔案暫留 common_tools，待兩台車的現行搬遷提交完成後再獨立為 bench 工具。一次性排查不得覆蓋正式韌體，應放入 investigations。
